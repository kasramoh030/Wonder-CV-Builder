# v1.0.0 — first release

## What this is

Wonder CV Builder builds a CV that fits the market it is being sent to, and
does it without an account, a subscription or a network connection.

## Highlights

- **Market-aware documents.** Six rule packs (Iran, Europe, Germany, the
  United Kingdom, the United States, international) decide the section order,
  the paper size, the date convention, the photo policy and which personal
  details are conventional. The rules are data files, so a new market is a
  JSON file rather than a code change.
- **Privacy by default.** Date of birth, marital status, nationality, gender,
  photo, national ID and exact address are off in every market until the user
  turns them on.
- **Eleven CV types**, from a first resume to a PhD or scholarship CV, plus a
  dedicated ATS layout: single column, standard headings, no photo, no
  graphics, no tables.
- **A real PDF engine.** A4 by default and US Letter for the United States,
  multi-page with page-break rules that keep a heading with its content,
  selectable and searchable text, embedded fonts including full Persian, right
  to left layout, clickable links.
- **An analyser that explains itself.** Offline scoring across structure,
  content, ATS-readiness, language and (when a job advert is pasted) job
  match, with every finding written as a problem, a fix and a priority. The
  score is presented as an estimate, with the disclaimer the brief requires.
- **Job-advert comparison** with found and missing terminology, and an
  explicit rule that a missing term is only worth adding if the experience is
  real.
- **Import** from PDF, DOCX and plain text, parsed on the device, with a
  mandatory review step before anything reaches the library.

## Known limitations, stated plainly

- **The online AI assistant is not in this build.** The offline analyser is
  complete; the optional assistant that would use your own API key is
  documented (`docs/AI_BYOK.md`) but not implemented. Nothing is faked.
- **No cloud sync.** A CV does not follow you to another device by itself;
  the JSON backup export is the mechanism.
- **Image import needs OCR**, which this build does not ship. The app says so
  instead of guessing at the text in a picture.
- **The application bundle is signed with a debug key in this repository's
  CI** until release signing secrets are configured. See `docs/RELEASE.md`.

## Compatibility

- Android 7.0 and newer (minSdk 24)
- Targets Android 16 (targetSdk 36)
- English, Persian (RTL) and German

## Permissions

Internet only, and only for the online/offline indicator and the optional
(not yet implemented) AI assistant. No storage, camera, microphone, contacts,
location or notification permission. See `docs/PERMISSIONS.md`.
